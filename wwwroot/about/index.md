# About

**TKVSC** stands for **T**ears of the **K**ingdom **V**isual **S**tudio **C**ode Extension.

It is a Visual Studio Code extension for editing and browsing **Tears of the Kingdom** (**TotK**) game files, with a focus on containing the modding process within a single editor.

TKVSC is developed and maintained by [TKVSC-Team](#the-team).
